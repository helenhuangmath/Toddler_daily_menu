# 家庭菜谱图库 · Family dish photos

把菜的照片放在这个文件夹里，发布后全家每部手机的 App 都能在 **灵感 → 家庭图库** 里看到，菜单里也会自动配图。

## 怎么上传（手机或电脑都可以）

1. 打开 https://github.com/helenhuangmath/Toddler_daily_menu/tree/main/gallery
2. 点右上角 **Add file → Upload files**（手机上可能要先点 “…” 才能看到）。
3. 选择照片，拉到最下面点 **Commit changes**。
4. 大约 1–2 分钟后网站自动更新，App 里下拉刷新或重新打开即可。

## 文件名就是菜名

- `番茄炒蛋.jpg` → 菜名“番茄炒蛋”
- 在方括号里加标签（空格分开）：`番茄炒蛋 [晚餐 大宝].jpg`
  - 餐次：`早餐` `午餐` `晚餐` `加餐`（或 breakfast / lunch / dinner / snack）
  - 给谁：写孩子在 App 设置里的名字，例如 `小宝` `大宝`
- 想写做法：再上传一个同名的 `.txt` 文件，例如 `番茄炒蛋 [晚餐 大宝].txt`，每行一步。

App 会从菜名里认出食材（比如“南瓜鸡肉粥”→ 南瓜、鸡肉），用来给菜单里的菜配图，并在家里食材够的时候把这道菜放进新菜单。

也可以上传菜单截图、小红书图片等灵感图，文件名随便写。在 App 的 **灵感 → 家庭图库** 里点 **✨ AI 识别**，AI 会读出图里的菜名、食材、适合哪个孩子和做法（需要在设置里填 Anthropic API 密钥；识别结果保存在这部手机上）。
支持 JPG、PNG、WEBP。照片最好小于 2 MB。
